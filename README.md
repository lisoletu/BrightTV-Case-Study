# BrightTV Viewership Analysis 📺

## Project Overview

This project is a data analytics case study focused on analysing BrightTV's user profiles and viewing behaviour to generate insights that support **subscriber growth and viewer engagement**.

The analysis was conducted to help BrightTV understand its users, identify viewing patterns and consumption drivers, and develop data-driven recommendations for increasing engagement and growing its subscriber base.

## Business Objectives

The case study aimed to answer the following key questions:

* Who are BrightTV's users?
* When do users watch BrightTV?
* What viewing and audience patterns can be identified?
* What factors influence consumption?
* What strategies could BrightTV use to increase engagement and grow its user base?

## Project Process

The project followed an end-to-end data analytics workflow:

**Data Cleaning & Transformation → Exploratory Data Analysis → Dashboard Development → Insights → Business Recommendations**

SQL was used in Databricks to clean and transform the data, including handling missing values, standardising demographic fields, converting timestamps from UTC to South African time, and creating analytical variables.

## Deliverables

The project includes dashboards developed using multiple business intelligence and visualisation platforms:

* 📊 **Excel Dashboard**
* 📈 **Power BI Dashboard**
* 📉 **Lovable Dashboard**
* 📊 **Looker Studio Dashboard**
* 🧱 **Databricks Visualisations**
* 🎤 **Final Business Presentation**

The dashboards explore subscriber demographics, viewing behaviour, consumption patterns, and opportunities for increasing engagement.

## Key Outcome

The analysis translated BrightTV's user and viewing data into **actionable business insights and recommendations** aimed at improving viewer engagement and supporting subscriber growth.
